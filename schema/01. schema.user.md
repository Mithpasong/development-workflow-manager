# 01. `users` 테이블

사용자(회원) 계정 정보를 저장하는 테이블.

- **테이블명**: `users`
- **스키마**: `public`
- **정의 위치**: [`src/db/schema.ts`](../src/db/schema.ts)
- **마이그레이션**: [`drizzle/0000_wet_krista_starr.sql`](../drizzle/0000_wet_krista_starr.sql)
- **ORM**: Drizzle ORM (드라이버: postgres.js)

---

## 컬럼 요약

| 컬럼 | 타입 | NULL | 기본값 | 제약 | 설명 |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | `gen_random_uuid()` | PK | 사용자 고유 식별자 |
| `email` | `varchar(255)` | NOT NULL | – | UNIQUE | 로그인 이메일(아이디) |
| `password_hash` | `varchar(255)` | NOT NULL | – | – | 해싱된 비밀번호 |
| `created_at` | `timestamptz` | NOT NULL | `now()` | – | 가입 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | `now()` | – | 마지막 수정 시각 |

---

## 컬럼 상세

### `id`
- **DB 컬럼**: `id`
- **TS 필드**: `id`
- **타입**: `uuid`
- **NULL 허용**: 아니오
- **기본값**: `gen_random_uuid()` (PostgreSQL이 자동 생성)
- **제약**: `PRIMARY KEY`
- **예시값**: `3f9a2c7e-1b4d-4a8e-9c2f-7e5d1a0b6c33`
- **설명**: 사용자 레코드의 기본 키. 애플리케이션에서 사용자를 참조하는 안정적인 식별자이며, 외부에 노출해도 추측이 어렵도록 순차 정수 대신 UUID를 사용한다.

### `email`
- **DB 컬럼**: `email`
- **TS 필드**: `email`
- **타입**: `varchar(255)`
- **NULL 허용**: 아니오
- **기본값**: 없음
- **제약**: `UNIQUE` (`users_email_unique`)
- **예시값**: `user@example.com`
- **설명**: 로그인 시 아이디로 사용하는 이메일 주소. 중복 가입을 막기 위해 유일(UNIQUE) 제약이 걸려 있다. 애플리케이션 레벨에서 소문자로 정규화해 저장하는 것을 권장한다. 길이 255는 이메일 표준(로컬 64 + `@` + 도메인 255 범위)을 고려한 일반적 상한.

### `password_hash`
- **DB 컬럼**: `password_hash`
- **TS 필드**: `passwordHash`
- **타입**: `varchar(255)`
- **NULL 허용**: 아니오
- **기본값**: 없음
- **제약**: 없음
- **예시값**: `$2b$10$N9qo8uLOickgx2ZMRZoM1e...` (bcrypt 해시)
- **설명**: **평문 비밀번호는 절대 저장하지 않는다.** bcrypt 등으로 해싱한 결과만 저장한다. bcrypt 해시는 약 60자이며, 알고리즘 변경을 대비해 255 길이로 여유를 둔다.

### `created_at`
- **DB 컬럼**: `created_at`
- **TS 필드**: `createdAt`
- **타입**: `timestamptz` (timestamp with time zone)
- **NULL 허용**: 아니오
- **기본값**: `now()`
- **제약**: 없음
- **예시값**: `2026-11-10T04:21:33.512Z`
- **설명**: 레코드가 처음 생성된(가입한) 시각. 타임존 포함(UTC 저장 권장).

### `updated_at`
- **DB 컬럼**: `updated_at`
- **TS 필드**: `updatedAt`
- **타입**: `timestamptz` (timestamp with time zone)
- **NULL 허용**: 아니오
- **기본값**: `now()`
- **제약**: 없음
- **예시값**: `2026-11-10T04:21:33.512Z`
- **설명**: 레코드가 마지막으로 수정된 시각. 현재는 애플리케이션에서 수정 시 직접 갱신해야 한다(자동 갱신 트리거 미설정).

## 참고 / 주의
- 비밀번호는 반드시 해싱(bcrypt 권장) 후 `password_hash`에만 저장한다.
- `email`은 유일 제약이 있으므로 중복 INSERT 시 오류가 발생한다(가입 시 중복 처리 필요).
- 스키마 변경 시: `src/db/schema.ts` 수정 → `npm run db:generate`(마이그레이션 생성) → `npm run db:migrate`(적용) → 이 문서 갱신.
