# 02. `projects` 테이블

사용자가 소유한 프로젝트를 저장하는 테이블. 한 사용자가 여러 프로젝트를 가질 수 있다(사용자 1 : N 프로젝트).

- **테이블명**: `projects`
- **스키마**: `public`
- **정의 위치**: [`src/db/schema.ts`](../src/db/schema.ts)
- **마이그레이션**: [`drizzle/0002_purple_human_torch.sql`](../drizzle/0002_purple_human_torch.sql)
- **ORM**: Drizzle ORM (드라이버: postgres.js)

---

## 컬럼 요약

| 컬럼 | 타입 | NULL | 기본값 | 제약 | 설명 |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | `gen_random_uuid()` | PK | 프로젝트 고유 식별자 |
| `user_id` | `uuid` | NOT NULL | – | FK → `users.id` (ON DELETE CASCADE) | 소유 사용자 |
| `name` | `varchar(100)` | NOT NULL | – | UNIQUE (전역) | 프로젝트 이름 |
| `created_at` | `timestamptz` | NOT NULL | `now()` | – | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | `now()` | – | 마지막 수정 시각 |

---

## 컬럼 상세

### `id`
- **DB 컬럼**: `id` / **TS 필드**: `id`
- **타입**: `uuid` · **NULL**: 아니오 · **기본값**: `gen_random_uuid()` · **제약**: `PRIMARY KEY`
- **예시값**: `b2d8c1a4-5e6f-47a0-9c3b-1d2e3f4a5b6c`
- **설명**: 프로젝트 레코드의 기본 키.

### `user_id`
- **DB 컬럼**: `user_id` / **TS 필드**: `userId`
- **타입**: `uuid` · **NULL**: 아니오 · **기본값**: 없음
- **제약**: `FOREIGN KEY` → `users.id`, **ON DELETE CASCADE** (`projects_user_id_users_id_fk`)
- **예시값**: `3f9a2c7e-1b4d-4a8e-9c2f-7e5d1a0b6c33`
- **설명**: 프로젝트를 소유한 사용자의 ID. 사용자가 삭제되면 해당 사용자의 프로젝트도 함께 삭제된다. 특정 계정의 프로젝트 목록을 조회할 때 이 컬럼으로 필터링한다.

### `name`
- **DB 컬럼**: `name` / **TS 필드**: `name`
- **타입**: `varchar(100)` · **NULL**: 아니오 · **기본값**: 없음
- **제약**: `UNIQUE` (`projects_name_unique`) — **전역(모든 사용자 통틀어) 유일**
- **예시값**: `Development Workflow Manager`
- **설명**: 프로젝트 표시 이름. 소유자와 무관하게 전체에서 이름이 중복될 수 없다. 중복 생성 시 `23505`(unique_violation)가 발생하며, API는 **409 `NAME_TAKEN`** 으로 응답한다.

### `created_at`
- **DB 컬럼**: `created_at` / **TS 필드**: `createdAt`
- **타입**: `timestamptz` · **NULL**: 아니오 · **기본값**: `now()`
- **예시값**: `2026-11-10T05:10:00.000Z`
- **설명**: 프로젝트 생성 시각(UTC 저장 권장).

### `updated_at`
- **DB 컬럼**: `updated_at` / **TS 필드**: `updatedAt`
- **타입**: `timestamptz` · **NULL**: 아니오 · **기본값**: `now()`
- **예시값**: `2026-11-10T05:10:00.000Z`
- **설명**: 마지막 수정 시각. 애플리케이션에서 수정 시 직접 갱신한다.

## 참고 / 주의
- 특정 계정의 프로젝트 목록: `SELECT ... FROM projects WHERE user_id = $1 ORDER BY created_at`.
- `users` 삭제 시 CASCADE로 프로젝트가 함께 삭제된다.
- 스키마 변경 흐름: `src/db/schema.ts` 수정 → `npm run db:generate` → `npm run db:migrate` → 이 문서 갱신.
- 관련: [[schema-docs-convention]], [`01. schema.user.md`](./01.%20schema.user.md)
