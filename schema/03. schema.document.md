# 03. `documents` 테이블

프로젝트의 각 단계(step)에 속한 **마크다운 문서**를 저장하는 테이블. 한 프로젝트가 여러 문서를 가질 수 있다(프로젝트 1 : N 문서).

- **테이블명**: `documents`
- **스키마**: `public`
- **정의 위치**: [`src/db/schema.ts`](../src/db/schema.ts)
- **마이그레이션**: [`drizzle/0004_flawless_karen_page.sql`](../drizzle/0004_flawless_karen_page.sql)
- **ORM**: Drizzle ORM (드라이버: postgres.js)

---

## 컬럼 요약

| 컬럼 | 타입 | NULL | 기본값 | 제약 | 설명 |
|---|---|---|---|---|---|
| `id` | `uuid` | NOT NULL | `gen_random_uuid()` | PK | 문서 고유 식별자 |
| `project_id` | `uuid` | NOT NULL | – | FK → `projects.id` (ON DELETE CASCADE) | 소속 프로젝트 |
| `step` | `varchar(50)` | NOT NULL | – | – | 소속 단계 (`background`, `proposal` 등) |
| `title` | `varchar(200)` | NOT NULL | – | – | 문서 제목 |
| `content` | `text` | NOT NULL | `''` | – | 마크다운 본문 |
| `created_at` | `timestamptz` | NOT NULL | `now()` | – | 생성 시각 |
| `updated_at` | `timestamptz` | NOT NULL | `now()` | – | 마지막 수정 시각 |

---

## 컬럼 상세

### `id`
- **타입**: `uuid` · **NULL**: 아니오 · **기본값**: `gen_random_uuid()` · **제약**: `PRIMARY KEY`
- **예시값**: `7c1f0f3e-2a44-4f1b-9d77-0b1c2d3e4f50`
- **설명**: 문서 레코드의 기본 키. URL 쿼리(`?doc=<id>`)로 선택 문서를 지정할 때 사용한다.

### `project_id`
- **TS 필드**: `projectId` · **타입**: `uuid` · **NULL**: 아니오
- **제약**: `FOREIGN KEY` → `projects.id`, **ON DELETE CASCADE** (`documents_project_id_projects_id_fk`)
- **예시값**: `b2d8c1a4-5e6f-47a0-9c3b-1d2e3f4a5b6c`
- **설명**: 문서가 속한 프로젝트. 프로젝트가 삭제되면 문서도 함께 삭제된다. **소유권 검증은 이 FK를 통해 `projects.user_id`와 조인해서 수행**한다.

### `step`
- **타입**: `varchar(50)` · **NULL**: 아니오 · **기본값**: 없음
- **예시값**: `background`
- **설명**: 사이드바 STEP 메뉴와 대응하는 단계 키. 현재는 `background`를 사용하며, 이후 `proposal` 등이 추가된다. 목록 조회는 `(project_id, step)`으로 필터링한다.

### `title`
- **타입**: `varchar(200)` · **NULL**: 아니오 · **기본값**: 없음
- **예시값**: `서비스 배경 정리`
- **설명**: 좌측 목록에 표시되는 문서 제목. 생성 시 기본값은 "제목 없는 문서".

### `content`
- **타입**: `text` · **NULL**: 아니오 · **기본값**: `''`(빈 문자열)
- **예시값**: `## 배경\n\n기존 프로세스는 ...`
- **설명**: **마크다운 원문**. 길이 제한이 없어 `varchar` 대신 `text`를 사용한다.

### `created_at` / `updated_at`
- **타입**: `timestamptz` · **NULL**: 아니오 · **기본값**: `now()`
- **설명**: 생성/수정 시각. 저장(PATCH) 시 `updated_at`을 애플리케이션에서 갱신한다. 좌측 목록에 수정일로 표시된다.

## 예시 레코드

| id | project_id | step | title | content | updated_at |
|---|---|---|---|---|---|
| `7c1f0f3e-…` | `b2d8c1a4-…` | `background` | `서비스 배경 정리` | `## 배경 …` | `2026-11-13T06:10:00.000Z` |

---

## 참고 / 주의
- 목록 조회: `SELECT ... FROM documents WHERE project_id = $1 AND step = $2 ORDER BY created_at`
- **접근 제어**: 문서 단건 조회/수정 시 `documents → projects` 조인으로 `projects.user_id`가 현재 사용자와 일치하는지 반드시 확인한다.
- 프로젝트 삭제 시 CASCADE로 문서가 함께 삭제된다.
- 스키마 변경 흐름: `src/db/schema.ts` 수정 → `npm run db:generate` → `npm run db:migrate` → 이 문서 갱신.
- 관련: [`02. schema.project.md`](./02.%20schema.project.md)
